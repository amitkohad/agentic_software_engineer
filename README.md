# Agentic Software Engineer

Enterprise-ready project scaffold for an autonomous software development lifecycle platform.

## Run the interfaces

Configure `OPENAI_API_KEY` and `OPENAI_MODEL`, install the project dependencies,
then start either interface:

```powershell
python main.py
streamlit run streamlit_app.py
```

Both interfaces execute the same dependency-injected LangGraph workflow. The
CLI writes generated projects beneath `generated_projects/<execution-id>`. The
Streamlit UI uses `data/agentic_sdlc.sqlite3` for workflow state and generated
artifact content; it does not materialize generated source files on disk.
Saved executions can be reopened and their artifacts downloaded as an in-memory
ZIP archive from the UI.

## Architecture

The source tree follows Clean Architecture. Dependencies point inward: API and infrastructure adapters depend on application use cases; application depends on the domain; domain stays framework-independent.

| Path | Purpose |
| --- | --- |
| `src/agentic_software_engineer/domain/` | Core business entities, value objects, and domain services; no framework or provider dependencies. |
| `src/agentic_software_engineer/application/` | SDLC use cases and port interfaces that coordinate domain behavior. |
| `src/agentic_software_engineer/infrastructure/` | Outbound adapters, configuration, OpenAI/LangGraph integrations, and dependency-injection wiring. |
| `src/agentic_software_engineer/api/` | FastAPI delivery layer and versioned HTTP route definitions. |
| `src/agentic_software_engineer/agents/` | Specialized autonomous agents, such as planning, coding, review, and testing agents. |
| `src/agentic_software_engineer/orchestrator/` | LangGraph workflow definitions, state, routing, and execution coordination. |
| `src/agentic_software_engineer/prompts/` | Version-controlled prompt templates and prompt policy assets. |
| `src/agentic_software_engineer/tools/` | Agent-callable tool contracts and implementations. |
| `src/agentic_software_engineer/memory/` | Short- and long-term agent memory abstractions and adapters. |
| `src/agentic_software_engineer/ui/` | Presentation-layer assets for a future operator interface. |
| `generated_projects/` | Isolated workspace root for applications generated by the platform (for example, a URL Shortener). |
| `tests/unit/` | Fast, isolated tests for domain and application behavior. |
| `tests/integration/` | Tests covering infrastructure adapters and cross-layer interactions. |
| `tests/e2e/` | End-to-end tests of externally observable platform workflows. |
| `docs/architecture/` | Architecture decision records and design documentation. |
| `scripts/` | Development, operational, and automation scripts. |

## Technology baseline

Python 3.12, FastAPI, LangGraph, OpenAI SDK, Pydantic, and a dependency-injection container will be introduced during implementation. This scaffold intentionally contains no executable application code.
